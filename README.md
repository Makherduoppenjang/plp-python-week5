# PLP Python Week 5 Assignment: Countdown, Guessing Game & Loop Patterns

## File Descriptions
- `countdown.py`: Uses a `while` loop to count down from a user-provided integer to 1 and outputs a final blast-off message.
- `guess_game.py`: Implements a number-guessing game using a `while` loop, dynamic high/low hints, and an attempt counter.
- `spell_it_out.py`: Demonstrates character iteration using `for` loops to display individual characters, numbered letters, and total length.

## Reflection on Loops
You reach for a `while` loop when you don't know in advance how many times an operation needs to repeat, as it depends on a condition remaining true (like waiting for a user to guess the correct secret number). Conversely, a `for` loop is ideal when you are iterating over a sequence with a known, definite length, such as cycling through every character in a string or items in a list.
